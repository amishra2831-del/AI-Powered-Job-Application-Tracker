# Local Development — Job Dekho

Quick notes to run this project locally for development.

## Prerequisites
- Node.js v18+
- (Optional) MongoDB running locally or MongoDB Atlas
- OpenAI API key (optional for AI features)
- Google OAuth credentials (optional for Google sign-in)

## Backend (server)
1. Install dependencies:
```bash
cd server
npm install
```
2. Copy environment example and fill values:
```bash
copy .env.example .env  # PowerShell
# or
cp .env.example .env    # WSL / Git Bash
```
- Required for full functionality: `MONGO_URI`, `SESSION_SECRET`, `JWT_SECRET`, `OPENAI_API_KEY`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.
- If you do not provide `MONGO_URI` or Google credentials, the server will run in a limited dev mode (DB and Google OAuth skipped).

3. Start server (development):
```bash
npm run dev
```
- Server default: `http://localhost:5000`
- Health check: `GET /health`

## Frontend (client)
1. Install dependencies:
```bash
cd client
npm install
```
2. (Optional) Copy env example:
```bash
copy .env.example .env
```
3. Start dev server:
```bash
npm run dev
```
- Frontend default: `http://localhost:5173`

## Verify
- Backend health: `curl http://localhost:5000/health`
- Frontend: open `http://localhost:5173` in your browser

## Notes & Troubleshooting
- If the server crashes with OAuth errors, set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` in `server/.env`, or run without them (optional).
- To enable DB features, set a valid `MONGO_URI`.
- Development defaults are provided: the server will use a fallback `SESSION_SECRET` when none is provided, and will skip DB or OAuth if variables are missing.
